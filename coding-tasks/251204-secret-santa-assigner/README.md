
# Codeschool task for 04/12/25:

### Goal:
Build a script (in Python) that randomly assigns Secret Santa pairs.

### Requirements:
- Input: list of names + exclusion pairs (e.g., Alice → Bob not allowed). Example of names is `participants.csv` and example of exclusion pairs is `exclude_pairs.csv`.
- Rules:
  - No one gets themselves
  - No pairs which should be excluded
- Output: print “Giver ➜ Receiver” list

### Stretch Goals:
- Write unit tests / use test-driven development
- Write results to CSV/JSON
